# OpaqueVault Homebrew Tap

Homebrew formulae for the [OpaqueVault](https://opaquevault.com) CLI (`ov`) — a zero-knowledge, quantum-safe secret manager built for AI coding agents. Your secrets are encrypted client-side; the server only ever stores ciphertext, and your AI agent never sees a plaintext value.

## Install

```bash
brew install opaquevault-brew/tap/ov
```

Or tap first, then install:

```bash
brew tap opaquevault-brew/tap
brew install opaquevault-brew/tap/ov
```

Use the fully-qualified name — a bare `brew install ov` installs homebrew-core's `ov`, an unrelated terminal pager. If you already have that package installed, run `brew unlink ov` first to avoid a `bin/ov` conflict.

Works on macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64).

## Get started

```bash
ov init          # writes secret-handling rules for your AI coding tools
ov auth login    # authenticate
```

`ov init` auto-detects Claude Code, Cursor, Windsurf, GitHub Copilot, Aider, Zed, Continue, and Cline, and writes the appropriate rules file for each.

- Quickstart: https://opaquevault.com/docs/quickstart
- Full installation guide (Linux script install, Windows, troubleshooting): https://opaquevault.com/docs/cli/installation

## Update

```bash
brew upgrade ov
```

## Uninstall

```bash
brew uninstall ov
brew untap opaquevault-brew/tap
```

## Release verification

The formula downloads binaries from `releases.opaquevault.com` and pins their SHA-256 checksums. Independently of Homebrew's checks, every release's checksums file is signed with the OpaqueVault minisign key, published at [opaquevault.com/.well-known/ov-release.pub](https://opaquevault.com/.well-known/ov-release.pub).

How to verify, and what to do if verification fails: https://opaquevault.com/docs/security/release-signing
